# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary users are Can Tho University (CTU) students planning their semester course schedules, especially under high time pressure during registration windows on the university's MyCTU portal. They need a fast, trustworthy tool to eliminate manual Excel/paper scheduling, prevent course time overlaps, accommodate personal constraints (part-time jobs, campus travel times, morning/afternoon shifts), and monitor class capacity in real time.

## Product Purpose

The CTU Scheduler website serves as the official landing page, download portal, and knowledge hub for the open-source CTU Scheduler desktop application. Success means effectively showcasing the desktop app's capabilities, facilitating smooth and safe downloads of the latest releases, providing transparent disclaimers and operational instructions (such as captcha handling and local execution), and introducing the student developer team.

## Positioning

The authoritative, student-focused web portal for Can Tho University's premier automated course scheduling tool. Unlike generic calendar tools or manual spreadsheets, it represents a dedicated utility tailored specifically to CTU's academic structure and MyCTU system, emphasizing complete local privacy (no third-party credential servers), intelligent multi-schedule generation, and live seat tracking.

## Operating Context

- Used by students during pre-registration and registration crunch periods at the beginning of academic semesters.
- Accessed on both desktop and mobile browsers to discover features, review FAQs/disclaimers, and obtain desktop installation files (hosted on GitHub Releases).
- Connected to CTU academic workflows, linking to the GitHub open-source repository, release assets, issue trackers, and developer social channels.

## Capabilities and Constraints

- **Capabilities:** Fast Single-Page Application (SPA) structure presenting Hero overview, core feature highlights with media previews, direct download section with release guidance, comprehensive terms of use and liability disclaimers, frequently asked questions (FAQ), and developer team credits.
- **Localization:** Vietnamese-primary interface catering to the local CTU student community, with bilingual support/toggle for English.
- **Technical Constraints:** Static frontend architecture powered by Vite, Tailwind CSS, and Vanilla JavaScript, optimized for fast delivery via platforms like Cloudflare Pages, Vercel, or GitHub Pages without requiring a backend server.
- **Safety Disclaimers:** Must accurately preserve and display disclaimers regarding the desktop app's local-only operation, MIT license terms, and non-liability regarding MyCTU server downtime, structural changes, or captcha checks.

## Product Principles

1. **Clarity and Trust First:** Course registration is critical for students; download buttons, system requirements, and security assurances must be prominent, accurate, and unambiguous.
2. **Focus on Real Student Needs:** Highlight solutions to real friction points (seat availability monitoring, avoiding cross-campus rush, balancing study with work).
3. **Total Transparency on Privacy:** Make it immediately clear that student credentials remain strictly local to the user's computer and are never collected or stored on external servers.
4. **Frictionless & Responsive:** Maintain an ultra-fast, clean landing page experience that functions seamlessly across phones, tablets, and desktop computers.

## Accessibility & Inclusion

Ensure high color contrast ratios, clear typography for both Vietnamese and English text, accessible interactive elements (clear focus indicators and descriptive buttons), and smooth responsive behavior across all device viewports.
